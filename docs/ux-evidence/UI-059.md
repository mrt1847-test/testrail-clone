# UI-059 — 이동/복사 목적지 경로

Completed: 2026-09-20

## Result

- Target section 옵션이 `Checkout / Login` vs `Authentication / Login`처럼 부모 경로로 구분된다.
- 저장 전 Destination 요약이 선택 경로를 보여 준다.
- 3건 Move 후 실제 `sectionId`가 Authentication/Login과 일치하고, Cancel은 소속을 바꾸지 않는다.

## Reproduction

- Fixture: duplicate Login under Checkout and Authentication (`ui-059-fixture.json`).
- Before: options included two identical `— Login` labels — [before 1280](./ui-059-before-1280x720-chooser.png), [options](./ui-059-before-options.json).
- Cause: `CaseBulkRelocationDialog` used depth dashes (`—`.repeat(depth) + name) without parent path; list order could also make Payment look nested under an unrelated parent.

## Change

- `sectionDestinationOptions` / tree-order path labels in `sectionTreeModel.ts`.
- `CaseBulkRelocationDialog` consumes `{ id, label }` paths + Destination summary; `aria-label="Target section"`.
- `CaseListPane` relocation options use path helper; drop-confirm uses `sectionPathLabel`.

## Verification

- `npx vitest run apps/web/src/features/cases/utils/sectionTreeModel.test.ts` — 3 passed.
- `npm.cmd run lint -w apps/web`, `npm.cmd run build -w apps/web` — pass.
- Live after options: Checkout / Login + Authentication / Login, no bare `— Login` (`ui-059-after-options.json`).
- Live move C5/C6/C7 → Authentication/Login; keep unchanged on Cancel (`ui-059-live-verify.json`, moveOk/cancelUnchanged).
- Screens: [after 1280](./ui-059-after-1280x720-chooser.png), [after 390](./ui-059-after-390x844-chooser.png) (`overflowX=false`).

## Exception

- Native Tab cycle not used (E02/UI-062). Dialog focus/`aria-label` checked.
- Section-tree MoveCopyChooser already used `sectionPathLabel`; this unit fixed the bulk case chooser reported in J07.
