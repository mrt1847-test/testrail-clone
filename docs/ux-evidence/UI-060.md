# UI-060 — 섹션 범위와 개수 안내

Completed: 2026-09-20

## Result

- Auth 직접/하위/전체 범위가 각각 **0 / 1 / 3** cases로 목록·안내·live region과 일치한다.
- 범위 전환 로딩 중에는 **Updating…** / `Updating case count`만 발표하고 가짜 `0 cases`를 내지 않는다.
- 트리 quick-add 후 suite summary가 **3 → 4 cases**로 갱신되고 목록도 함께 맞는다.

## Reproduction

- Fixture: Authentication(+Login 1) / Billing(2) — before shots `ui-060-before-1280x720-auth-{direct,subtree,all}.png`, `ui-060-repro.json`.
- Causes:
  1. 로딩 중 목록 chrome이 사라지거나 빈 배열을 `0 cases`로 발표.
  2. `SectionTreePane.invalidate`가 `suite-summary`를 빼먹음.
  3. 트리 `+` / quick-add 폼 클릭이 treeitem까지 전파되어 제출 전 폼이 언마운트됨 (`Form submission canceled because the form is not connected`).

## Change

- `CaseQueryScopeControl`: `caseCount: number | null` → `Updating…`, sr-only `role=status` aria-live.
- `CaseListPane`: 로딩 중에도 scope 컨트롤 유지(`caseCount=null`); `scopedCaseCount`는 로딩/미수신 시 null.
- `SectionTreePane.invalidate`에 `suite-summary` 포함; `+`에 `stopPropagation`.
- `SectionTreeQuickAddCase`: 폼 click/keydown `stopPropagation`으로 제출 유지.
