# UI-063 — Overview/Milestone 집계 문맥

Completed: 2026-09-20

## Result

- Overview 한 줄이 **고유 케이스 수**와 **열린 Run의 테스트 인스턴스 remaining**을 구분한다.  
  예: `3 cases · 1 passed · 1 failed · 4 tests remaining across open runs` (closed Run 인스턴스는 remaining에 넣지 않음).
- Milestone 요약: `N linked active runs` / `No linked active runs` — 프로젝트 전체 active runs와 혼동하지 않음.
- 메모리 API: `/overview`의 `totalCases`를 catalog에서 집계; `/milestones/:id/runs`가 `run.milestoneId`로 연결 Run을 반환 (빈 Map 버그 수정).
- Linked Run에서 실제 Run으로 이동 확인. 미연결 Beta는 milestone 목록에 없음.

## Reproduction

- Fixture: 3 cases · Alpha(open, linked) · Beta(open, unlinked) · Closed(closed, linked); Alpha 1 passed, Beta 1 failed.
- Before: Overview `1 passed · 0 failed · 8 remaining`(closed 포함 합산, cases 문맥 없음); `/overview` `totalCases: 0`; milestone 상세 **No linked runs**이지만 summary `runCount: 2`.
- Evidence: `ui-063-before-*.png`, `ui-063-before-snap.json`, `ui-063-fixture.json`.

## Change

- Server: memory overview case count; milestone runs from repo by `milestoneId` (`reports.routes`, `milestones.routes`, `app.ts`).
- Web: open-run-only execution rollup (`projectApi`); `formatOverviewExecution` / `formatOverviewMilestoneRuns`; Overview + columns labels; ExecutionSummaryChart 문맥 문구.
- Test: milestone-rollup creates a case; asserts linked runs endpoint.

- `npm.cmd run lint -w apps/web`, `build -w apps/web`, `build -w apps/server` — pass.

## Exception

- Plan entry가 별도 Run으로 생성된 경우 그 Run 인스턴스는 open-run 합산에 포함(중복 Plan+Run 이중 가산은 없음).
- Prisma 경로 overview/totalCases는 기존 DB count 유지; 이번 live는 in-memory.
