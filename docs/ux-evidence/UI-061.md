# UI-061 — 긴 프로젝트 이름 표시

Completed: 2026-09-20

## Result

- 헤더 프로젝트 스위치어가 긴 이름의 **앞글자를 보존**한 뒤 줄인다 (`UI-061 Checkout…` / `매우긴…` / `ExtremelyLong…`).
- `title`·`aria-label`·메뉴 항목으로 전체 이름 접근 가능.
- 1440/1280/390에서 Account·Suite와 겹침 없음, 페이지 가로 넘침 없음.

## Reproduction

- Fixture: EN/KO/공백없음 긴 이름 (`ui-061-fixture.json`).
- Before 1280: 트리거가 `inline-flex` + `justify-center` + `truncate`라 가운데 잘림 → 보이는 글자가 `tremely Long…`처럼 앞 `Ex`/`UI-061` 손실 (`ui-061-before-1280x720-en.png`, `ui-061-repro.json`).

## Change

- `ProjectSwitcher`: 라벨을 내부 `truncate` span으로 분리, `!justify-start`, `title`=전체 이름.
- 좁은 헤더에서 `flex-1 min-w-0`로 남는 폭만 사용하고 Suite는 `shrink-0` 유지.
