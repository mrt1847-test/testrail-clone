- 최종 판정은 `docs/ux-evidence/UI-021.md`에 남긴다. 미해결 코드 결함은 별도 수정 후보로, 환경/사람 대기는 E 항목으로 구분한다. UI-021이나 UX 체크를 임의 완료해 반복을 끝내지 않는다.
